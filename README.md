# Profit Tracker

Standalone ecommerce profit intelligence software.

Profit Tracker reconciles Shopify orders, refunds, product costs, payment fees, fulfillment/shipping costs, operating expenses and Meta ad spend into an auditable profit ledger.

## Core principles

- Profit first: contribution profit and margin are primary; ROAS is diagnostic.
- Explain every dollar: dashboard totals drill into orders, products, channels and cost rules.
- Separate reported attribution from financial truth.
- Show break-even CPA and break-even ROAS alongside actual performance.
- Store integration credentials only on the backend.
- Mobile-first UI.

## Status

Initial production scaffold. Backend environment is intentionally separate from Avonent OS.
